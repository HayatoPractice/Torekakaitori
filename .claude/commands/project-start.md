以下のセッション開始手順を順番に実行してください。

## Step 1: 現在の状態把握

1. `git status` を実行して、未コミットの変更やローカルの状態を確認する。
2. `MINUTES.md` を読み込み、前回セッションの TL;DR・完了事項・次のタスク・注意事項を把握する。
3. インシデント管理を参照する（任意推奨）：
   - `/Users/sasakihayato/アプリ作成関連/アプリ作成/インシデント管理/_PRE_CHECKLIST.md` を確認
   - `INCIDENT_INDEX.md` の「技術スタック別クイック検索」で関連タグを照合し、該当ファイルだけ読む

## Step 2: 未完了タスクの確認

1. `TODO/` フォルダが存在する場合、`ls TODO/` で手順書ファイルを確認する。
2. 各手順書の未完了タスク（`- [ ]`）を抽出し、進捗サマリー（完了N/全N件）を表示する。
3. `[高]` ラベルのタスクを最優先として整理する。

## Step 3: ホームページ原本との差分確認（§30）

```bash
python3 scripts/compare_origins.py
```

ホームページ作成原本側の新着コミットを確認し、アプリ作成原本に活用できる変更があれば提案する。
（compare_origins.py が存在しない場合はスキップ）

## Step 4: 起動報告の提示

すべての読み込みが完了したら、以下のフォーマットで「起動報告」を提示し、今日のタスクの確認を求める。
