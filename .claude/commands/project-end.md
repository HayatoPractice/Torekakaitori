---
description: セッション終了時の引き継ぎ情報・議事録を更新し、全アプリへ同期する
---

以下のセッション終了手順を順番に実行してください（CLAUDE.md §セッション終了プロトコル 準拠）。

## Step 1：MINUTES.md の TL;DR を最終状態に更新

`MINUTES.md` の TL;DR セクションを現在の状態に書き換える（上書き禁止・更新のみ）：
- 現在地（何をどこまでやったか）
- 前回完了（このセッションで終わったこと）
- 次のタスク（次回最初にやること）
- 注意事項（引き継ぎで伝えるべき警告・制約）

## Step 2：TODO の未完了タスクを MINUTES.md へ転記

`TODO/` フォルダの各手順書から `- [ ]` の未完了タスクを抽出し、MINUTES.md の「次のタスク」欄へ転記する。

## Step 3：変更ファイルを MINUTES.md に記録

```bash
git diff --name-only HEAD
```

変更ファイルの一覧を取得し、MINUTES.md の「変更ファイル」欄に記録する。

## Step 4：同期プレビュー＆実行

```bash
python3 scripts/sync_to_apps.py --dry-run
```
プレビューを確認してから実行する：
```bash
python3 scripts/sync_to_apps.py
```

## Step 5：未コミットの変更をコミット＆push

```bash
git add -p  # または git add <変更ファイル>
git commit -m "..."
git push
```

push 先リポジトリを必ず確認すること（§22-3 他フォルダへの誤 push 厳禁）。

## Step 6：次回タスクをユーザーへ報告

```
┌────────────────────────────────────────┐
│ 【セッション終了】                      │
│ 完了：[このセッションで終わったこと]    │
│ 次回：[次のタスク名（MINUTES.md より）] │
│ 未完了TODO：N件（TODO/<ファイル名>.md） │
│ 保存：MINUTES.md 更新済 / 同期：N アプリ │
└────────────────────────────────────────┘
```
