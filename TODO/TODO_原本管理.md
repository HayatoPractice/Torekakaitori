# TODO_原本管理.md — TODO手順書ルール・テンプレート参照
最終更新：2026-06-17

> **このファイルの役割：**
> アプリ作成原本のTODOフォルダはルール参照・テンプレート置き場として使用します。
> 実際の作業手順書は **各アプリフォルダ** で独立して管理します（原本との連携なし）。
> 各アプリのTODOファイルの書き方ルールは `DOCS/APP_SHARED_RULES.md §23` を参照してください。

---

## 各アプリでのTODOファイル作成テンプレート

新しいアプリで手順書を作成する際は、以下をコピーして `TODO/TODO_<作業内容>.md` として保存してください。

```markdown
# TODO_<作業内容>.md — 作業手順書
作成日：YYYY-MM-DD ｜ 最終更新：YYYY-MM-DD

---

## 目的・背景
（この手順書で達成したいこと・ユーザーの意図・作業の概要）

## 手順（実施順）

- [ ] **[手順名]**
  - 内容：[何を・なぜ・どう行うか]
  - 対象：[ファイル・コマンド・画面など]
  - 完了条件：[何が確認できれば完了か]

## 完了済み手順
- [x] **[手順名]**：[完了内容・確認方法・完了日]

## 変更履歴
- YYYY-MM-DD：[変更内容]
```

---

## ルールまとめ（APP_SHARED_RULES.md §23 より）

| 操作 | 方法 |
|:---|:---|
| ✅ 完了 | `- [ ]` → `- [x]` に変更 |
| ➕ 追加指示 | 既存ステップの適切な位置へ差し込む |
| ❌ 削除指示 | ~~取り消し線~~ のみ追加（削除しない） → 理由と日付を末尾に記載 |
