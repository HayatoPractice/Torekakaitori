## 機能要件

### 確定済み要件

#### コアバリュー
複数のXアカウント（トレカ販売店・買取店など）の投稿（URL・テキスト・画像）を蓄積し、
BOX/パック単位の販売相場・買取相場を横断比較できるようにする。
店舗ごとの「販売⇔買取」の相場差を比較できることが差別化ポイント。

#### 前提・制約（重要な決定事項）
- **Xの自動巡回は行わない**。X APIは2026年2月以降、無料枠が廃止され従量課金制のみ
  （読み取り1件$0.005、月間読み取り上限200万件）となったため、規約遵守と無料運用を
  両立させるべく、投稿の取得はユーザーによる**手動投入**方式とした。
- 認証機能はなし（開発者本人の専用アプリとして運用）。

#### データ投入方式
- 投稿URLの貼り付け登録
- テキストの直接貼り付け（複数投稿分をまとめて貼ってもAIが自動で個別アイテムに分割）
- 画像の複数枚アップロード（一括投入対応）
- 各エントリに「対象アカウント」「投稿日」を紐付け（画像内に日付があれば自動抽出を試行、
  不可の場合は手入力）
- ブックマークレット/ブラウザ拡張でXの投稿URLをワンクリック登録

#### AI解析（Gemini API 無料枠を使用）
- テキスト・画像からBOX/パック名・価格・種別（販売/買取）を自動抽出
- 抽出信頼度スコアを表示し、低信頼度は確認待ちステータスにする
- 抽出結果を人間が確認・修正できるレビューUI
- 商品名の表記ゆれを統合する名寄せマスタ管理
- 重複投稿（同一URL・酷似内容）の検知・警告

#### 閲覧・分析機能
- 投稿日で絞り込み、その日の全エントリを横断参照
- アカウント別まとめページ（販売相場⇔買取相場の比較表示）
- BOX/パックごとの価格推移グラフ
- 販売⇔買取スプレッド（差額）の自動計算・表示
- 最安値・最高値・平均値のハイライト
- 価格急変の視覚的ハイライト（一定%以上の変動を強調表示。プッシュ通知は行わない）
- 買取最高値／販売最安値ランキング
- 店舗ごとの価格傾向スコア
- 情報の鮮度表示（登録から何日経過したデータか）

#### エクスポート
- CSVエクスポート
- 相場まとめ画像の自動生成

### 明示的に対象外（今回は実装しない）
- 通知・リマインド系（発売日カレンダー、お気に入り通知、登録漏れチェックリスト）
- 将来拡張系（楽天市場API/Yahoo!ショッピングAPI連携、他TCGカテゴリへの拡張）
- Xからの自動投稿取得（有料APIが前提のため。将来、課金判断が変わった場合に再検討）

## 技術スタック（決定）

- フロントエンド／API：Next.js（App Router）+ TypeScript
- スタイリング：Tailwind CSS
- DB：Neon（サーバーレスPostgres、無料枠）。`@neondatabase/serverless` で直接SQLを発行
- 画像保存：Neonにファイルストレージが無いため、DBにbytea（バイナリ）として直接保存
- AI解析：Google Gemini API（無料枠）
