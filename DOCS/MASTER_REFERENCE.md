# AIエージェント開発・プロンプトエンジニアリング統合リファレンス

本ドキュメントは、Anthropicの最新ツール(Claude Code)、プロンプトエンジニアリングのベストプラクティス、および高度な科学的自動化(PMC論文)の知見を統合した、プロジェクト強化のためのマスターガイドである。

---

## 1. ツール・環境: Claude Code エージェントの活用
自律型エージェントとしての能力を最大限に引き出すための指針。

- **エージェント的ワークフロー:** AIに単なるコード提案ではなく、調査・設計・実装・検証の一連のプロセス（Agentic Workflow）を完遂させる。
- **ターミナル直接操作:** 読み取り、編集、コマンド実行、Git操作をAIに許可し、開発ライフサイクルを自動化する。
- **自動メモリとCLAUDE.md:** プロジェクト固有の規約やデバッグ知見を `CLAUDE.md` に集約し、AIがセッションを超えて「学習」できるようにする。
- **MCP (Model Context Protocol):** 外部ドキュメントやデータソースを動的に結合し、コンテキストの壁を打破する。

## 2. 戦略・思考: プロンプトエンジニアリングの極意
AIの出力を精密に制御し、再現性と品質を確保するための技術。

- **XML構造化:** `<instructions>`、`<context>`、`<rules>` 等のタグを用いて、情報を論理的に分離・定義する。
- **思考の連鎖 (Chain-of-Thought):** 結論を出す前に `<thinking>` ブロックで論理プロセスを記述させ、複雑な推論を安定させる。
- **Role Prompting:** 専門家の役割（Senior Architect, Security Auditor等）を明確に指定し、適切な視点と語彙を誘発する。
- **Few-Shot Learning:** 具体的かつ正確な入出力例（Examples）を提示し、ゼロから推論するリスクを軽減する。
- **プロンプト・チェイニング:** 巨大なタスクを、単一目的のプロンプトの連続体に分解して処理する。

## 3. 実践・応用: 科学的自動化と高度なワークフロー (PMC12782108)
複雑な専門領域におけるLLMの活用と成功事例からの学び。

- **構造化プロンプトの優位性:** 曖昧な自然言語指示よりも、入出力と手順を明確に定義した構造化プロンプトの方が成功率が高い。
- **未知のツールの活用:** 学習データにない最新ツールでも、公式ドキュメント（README等）をコンテキストに注入することで、AIは正しく使いこなせる。
- **パイプラインの進化:** 既存の古いコードやツールを特定し、最新のより効率的な代替案へと自律的にリファクタリングする能力を活用する。
- **多段階ワークフローの自動化:** 複雑な科学計算やパイプラインのように、依存関係の強い多段工程も、適切な構造化により自動化が可能。

---

## 4. 統合的教訓
- **検証の自動化:** コードを書くだけでなく、それが「正しい」ことをAI自身がテストを通じて証明する仕組みが必須。
- **継続的なリファイン:** プロンプトは一度書いて終わりではなく、実証的な評価に基づいて反復的に改善し続けるべきである。
- **コンテキストの純度:** 必要な情報のみを、最適なタイミングで、最適な構造で提供することがAIのパフォーマンスを決定づける。
