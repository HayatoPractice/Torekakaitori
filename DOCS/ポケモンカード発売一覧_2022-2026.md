# ポケモンカード（日本国内版）発売一覧（2022年1月1日〜2026年9月時点／予定含む）

## この文書について

ユーザーが作成した2つのリスト（①レギュレーションページ等をベースにした発売一覧、②メタゲーム分析を含む報告書）を突き合わせ、相違点をすべて公式サイト・複数の一次情報で確認した上で統合したもの。

**対象範囲**：拡張パック・強化拡張パック・ハイクラスパックに加え、構築デッキ（スターターセット等）・特別セット・BOX商品のみ。個々の1枚単位のカード、デッキシールド・プレイマット・カードケース等の周辺グッズは対象外（ユーザーの指示により除外）。

**統合時に行った修正**（2026-09-03、公式サイト・複数の独立した情報源でファクトチェック済み）：

|---|---|---|---|

**もう一方のリストにしか無かったが、確認の結果どちらも実在の商品だったため統合したもの**：スペシャルカードセット（草のリーフィアVSTAR／氷のグレイシアVSTAR）、Pokémon GO スペシャルセット／カードファイルセット、コンゴウ団／シンジュ団スペシャルセット、ジャンボカードコレクション、exスタートデッキ テラスタル カイリュー／ヨクバリス、いつでもどこでも バトルアカデミー、コレクションファイルセット N／リーリエ、スペシャルBOX ポケモンセンタートウホク／ヒロシマ／フクオカ、ブラックボルト・ホワイトフレア カードファイルセット（各項目とも公式サイトまたは複数の専門メディアで実在・発売日を確認済み）。

**再販・追加販売について**：初回発売後に抽選等での追加販売（再販）が行われた商品には、下表の商品名に「（※再販あり）」と注記した。2026-09-03、公式サイト・専門メディア複数で「再販の有無」のみを確認済み（正確な再販日までは検証していない）。

- **再販ありと確認できたもの**：ポケモンカードゲーム Classic、スペシャルBOX ポケモンセンタートウホク／ヒロシマ／フクオカ、スターバース、ポケモンカード151、VSTARユニバース、クレイバースト／スノーハザード、熱風のアリーナ（発売当日に突如販売延期になった経緯あり）、テラスタルフェスex、バトルパートナーズ、ステラミラクル、超電ブレイカー、マリィのモルペコ＆オーロンゲex／ダイゴのダンバル＆メタグロスex、ブラックボルト／ホワイトフレア（公式に追加生産の告知あり）、メガブレイブ／メガシンフォニア、インフェルノX／MEGAドリームex（公式に再販抽選の告知あり）、ムニキスゼロ、スタートデッキ100 バトルコレクション（公式に追加生産の告知あり）

- **再販の有無を確認できなかったもの（情報が見つからなかっただけで、無いと断定はできない）**：ニンジャスピナー、アビスアイ、楽園ドラゴーナ、変幻の仮面、ナイトワンダラー、コレクションファイルセットN／リーリエ、バトルマスターデッキ／VSTAR&VMAXハイクラスデッキ／スタートデッキGenerations等の構築デッキ系商品全般（この系統は基本的に数量限定生産のため再販記録自体が乏しい傾向）
- 上記以外の商品（2022年の他の拡張パック等）は今回の再販調査の対象外
