## SECTION 1：全アプリ共通の必須事項

### 1-1. プライバシーポリシーが必要な条件

以下のいずれかに該当する場合、プライバシーポリシーの設置が必須：

```
□ ユーザー登録・ログイン機能がある
□ Google Analytics / Firebase Analytics を使用している
□ メールアドレスを収集する
□ Cookie / LocalStorage / SessionStorage を使用している
□ ユーザーの行動データを収集・分析している
□ 外部サービス（Stripe等）と個人情報を連携している
```

**テンプレート参考：**
- 「プライバシーポリシー生成ツール」（無料ジェネレーター）
- 「みんなの利用規約」

---

### 1-2. 利用規約が必要な条件

```
□ 不特定多数のユーザーに使わせる（無料でも必須）
□ 有料サービスを提供する
□ ユーザーがコンテンツを投稿・共有できる機能がある
□ AIが生成したコンテンツをユーザーが利用する機能がある
```

---

### 1-3. 特定商取引法に基づく表記

**必要な条件：** 有料サービス・商品の販売を行う場合

**必須記載項目：**
```
□ 販売事業者の氏名（屋号）
□ 所在地
□ 電話番号（または問い合わせフォームURLで代替可）
□ メールアドレス
□ 販売価格（税込）
□ 支払方法
□ 支払時期
□ サービス提供時期・期間
□ 返品・キャンセルポリシー
□ 動作環境（アプリの場合）
```

---

### 1-4. Cookie 同意（GDPR / 国内法）

**EU ユーザーにサービスを提供する場合：** GDPR に基づく Cookie 同意バナーが必須。

**日本国内のみの場合：** 個人情報保護法に基づく説明が必要（同意バナーは任意だが説明は必須）。

```tsx
// Cookie 同意バナーの実装例（日本国内向け）
// プライバシーポリシーへのリンクと簡単な説明を表示
```

## SECTION 2：個人情報保護法の要点

### 2-1. 個人情報の取り扱い原則

```
□ 利用目的を明示する（プライバシーポリシーに記載）
□ 利用目的以外に使用しない
□ 必要最小限の情報のみ収集する
□ 第三者提供時は同意を取得する
□ ユーザーからの開示・訂正・削除請求に対応できる体制を作る
□ 漏えい時は速やかに本人に通知する（漏えい等報告義務）
```

### 2-2. データ保存の要件

```tsx
// パスワードは必ずハッシュ化（Supabase Auth は自動で対応）
// 個人情報はデータベースで暗号化して保存
// ログにメールアドレス・電話番号・パスワードを出力しない

// APIレスポンスで不要な個人情報を返さない
// NG: ユーザー全フィールドを返す
const user = await supabase.from('users').select('*');

// OK: 必要なフィールドのみ返す
const user = await supabase.from('users').select('id, name, avatar_url');
```

## SECTION 3：業種別特殊要件

### 3-1. 医療・健康系

**該当するアプリ：** 病院予約・健康記録・症状チェック・薬の情報提供・医師相談

**禁止事項（医療広告ガイドライン）：**
```
❌ 「確実に治る」「必ず効果がある」等の断言表現
❌ 他の医療機関との比較（「〇〇より効果的」）
❌ 体験談・口コミを治療効果の根拠とする
❌ 医師・歯科医師以外が医学的な診断・治療を提供する
```

**必須事項：**
```
□ 「医療相談・診断の代替ではありません」の免責事項
□ 症状に関するコンテンツに「医師への相談を推奨」の記載
□ 個人の健康情報（センシティブ情報）の取り扱いに関する明示的な同意取得
```

---

### 3-2. 金融・投資系

**該当するアプリ：** 家計管理・資産記録・投資シミュレーション・ポイント管理

**禁止事項（金融商品取引法・景品表示法）：**
```
❌ 「必ず利益が出る」「元本保証」等の断言
❌ 根拠のない利益実績の表示
❌ 金融商品の販売・勧誘（無登録での取り扱いは違法）
```

**必須事項：**
```
□ 投資に関するコンテンツには「投資は自己責任です」の明記
□ シミュレーション結果に「将来の利益を保証するものではありません」の注記
□ 実際の金融商品販売を行う場合は金融庁への登録が必要
```

---

### 3-3. 不動産系

**該当するアプリ：** 物件検索・家賃計算・引越しサポート

**必須事項：**
```
□ 不動産取引の仲介を行う場合は宅地建物取引業免許が必要
□ 物件情報を掲載する場合は情報の正確性に関する免責事項
□ 個人情報（住所・収入等）の取り扱いに関する明示
```

---

### 3-4. 飲食・食品系

**該当するアプリ：** グルメ情報・レシピ・食事記録・デリバリー

**禁止事項（景品表示法・食品表示法）：**
```
❌ 根拠なく「ダイエット効果がある」等の健康効果の断言
❌ 「医師が推奨」等の誇大表現
❌ 食品の栄養成分表示の誤り
```

**必須事項：**
```
□ アレルギー情報の提供機能がある場合、情報の正確性の免責事項
□ 食品販売を行う場合は食品衛生法・消費者契約法に準拠
```

---

### 3-5. 教育系

**該当するアプリ：** 学習支援・塾・語学・資格

**必須事項：**
```
□ 未成年ユーザーが利用する場合、保護者への説明・同意取得の仕組み
□ 「合格保証」等の断言は根拠が必要
□ 個人情報の収集（学習履歴等）の目的明示
□ 13歳未満のユーザーには特に厳格な個人情報管理が必要（COPPA参考）
```

---

### 3-6. EC・売買系

**該当するアプリ：** ショッピング・フリマ・オークション

**必須事項：**
```
□ 特定商取引法の表記（SECTION 1-3 参照）
□ 返品・キャンセルポリシーの明記
□ 決済情報（カード番号等）はStripe等の決済代行に委託し、自社で保持しない
□ フリマ・売買の場合は古物商許可が必要な場合がある
```

---

### 3-7. 予約・マッチング系

**該当するアプリ：** 美容院・サービス予約・マッチング

**必須事項：**
```
□ キャンセルポリシーの明確な表示（キャンセル料の条件等）
□ マッチングサービスの場合、インターネット異性紹介事業の届出が必要な場合がある
□ サービス提供者と利用者の間で生じるトラブルに関する免責事項
```

## SECTION 4：リリース前の法的チェックリスト

```
【全アプリ共通】
□ プライバシーポリシーが設置されているか（必要な場合）
□ 利用規約が設置されているか（必要な場合）
□ フッターにプライバシーポリシー・利用規約へのリンクがあるか
□ 個人情報の収集時に同意を取得しているか

【有料サービスの場合】
□ 特定商取引法の表記ページがあるか
□ 価格（税込）が明記されているか
□ キャンセル・返品ポリシーが明記されているか

【業種別】
□ 該当する業種の特殊要件（SECTION 3）を確認したか
□ 禁止表現が含まれていないか確認したか
□ 必要な免責事項が記載されているか確認したか
```
